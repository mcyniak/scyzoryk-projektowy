Odczytuje pola ze zeskanowanych audytów (także pismo odręczne) do tabeli do sprawdzenia i pozwala pobrać pliki PDF per adres.

PDF (skany)Gemini / OpenAIKlucz API dla trybu AI

Aktualny ekran - wczytanie skanów, analiza pól i tabela do weryfikacji.

Krok po kroku

  1. Wybierz dostawcę rozpoznawania (ikonka klucza w nagłówku): Gemini, OpenAI albo Ręczny i wklej klucz API (tryby AI).
  2. Dodaj zeskanowane audyty PDF (możesz kilka naraz) i uruchom analizę.
  3. Sprawdź rozpoznane pola w tabeli - każde pole możesz poprawić ręcznie; pola niepewne są oznaczone do przeglądu.
  4. Jeśli jeden PDF zawiera wiele adresów - potwierdź podział na osobne pliki (nigdy nie dzieje się to samoistnie).
  5. Pobierz wynikowe PDF-y (jeden per adres) i opcjonalnie eksport tabeli do Excela.
Tryb Ręczny

Działa w pełni offline i bez klucza API - wszystkie pola są puste do wpisania z ręki, na podstawie podglądu skanu.

Obrót skanu

Aplikacja NIE obraca stron - wgraj skany już prawidłowo ustawione (stroną do góry), inaczej podgląd pól będzie krzywy.

Szczegóły pól i ekranów

Klucz API
Wpisz klucz API, żeby odblokować rozpoznawanie tekstu i pisma odręcznego. Robisz to raz na tym komputerze - ustawienie zostaje zapisane osobno od samej aplikacji i przetrwa kolejne aktualizacje.
Tabela z adresami (Excel)
Jeśli masz już plik Excela z adresami/numerami LP (np. częściowo uzupełnioną tabelkę adresową), wskaż go tutaj - program sprawdzi, jakich pól rzeczywiście brakuje, i będzie pytał tylko o nie.
Wgranie skanów
Możesz wgrać kilka plików naraz. Każdy zostanie rozpoznany osobno - jeśli plik zawiera kilka adresów, w następnym kroku sprawdzisz i potwierdzisz podział.
Podział na adresy
Program zaproponował podział na podstawie powtarzającego się nagłówka protokołu - sprawdź miniatury stron, w razie potrzeby popraw podział (przyciski między stronami) i nazwy adresów.
Tabela pól
Program rozpoznał większość pól automatycznie. Pola oznaczone na bursztynowo wymagają Twojej uwagi - sprawdź je na oryginalnej stronie (miniatury nad tabelką) i wpisz poprawną wartość ręcznie.
Zapis do Excela
Zostaw puste, jeśli teraz nie chcesz zapisywać do Excela - dostaniesz tylko gotowe PDF-y. Wybór rodziny (krok 3) dopasowuje nagłówki kolumn 1:1 do prawdziwego wzoru (LP, REZYGNACJA i pozostałe kolumny tabeli adresowej).
