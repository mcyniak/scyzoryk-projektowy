Odczytuje pola ze zeskanowanych audytów (także pismo odręczne) do tabeli do sprawdzenia i pozwala pobrać pliki PDF per adres.

PDF (skany)Gemini / OpenAIKlucz API dla trybu AI

Aktualny ekran - wczytanie skanów, analiza pól i tabela do weryfikacji.

Krok po kroku

  1. Wybierz dostawcę rozpoznawania (ikonka klucza w nagłówku): Gemini, OpenAI albo Ręczny i wklej klucz API (tryby AI).
  2. Dodaj zeskanowane audyty PDF (możesz kilka naraz) i uruchom analizę.
  3. Sprawdź rozpoznane pola w tabeli - każde pole możesz poprawić ręcznie; pola niepewne są oznaczone do przeglądu.
  4. Jeśli jeden PDF zawiera wiele adresów - potwierdź podział na osobne pliki (nigdy nie dzieje się to samoistnie).
  5. Pobierz wynikowe PDF-y (jeden per adres) i opcjonalnie eksport tabeli do Excela.
Tryb Ręczny

Działa w pełni offline i bez klucza API - wszystkie pola są puste do wpisania z ręki, na podstawie podglądu skanu.

Obrót skanu

Aplikacja NIE obraca stron - wgraj skany już prawidłowo ustawione (stroną do góry), inaczej podgląd pól będzie krzywy.

Gdzie szukać pomocy

Logi aplikacji: %LOCALAPPDATA%\ScyzorykProjektowy\Data\ocr-audytow\logs. Klucze API trzymane są lokalnie w %LOCALAPPDATA%\Scyzoryk i nigdy nie opuszczają komputera poza zapytania do wybranego dostawcy AI.
