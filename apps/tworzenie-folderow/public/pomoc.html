Pomoc — Tworzenie folderów
Wróć do narzędzia Panel główny

Na podstawie tabeli adresowej uzupełnia podfoldery inwestycji (WM, pompy, kolektory, kotły) w już istniejącym folderze.

XLSXfoldery

Aktualny ekran — ścieżka folderu inwestycji, tabela adresowa i podgląd planowanej struktury.

Krok po kroku

  1. Wskaż ścieżkę już istniejącego folderu inwestycji — przyciskiem Przeglądaj... albo wklejając ścieżkę ręcznie. Program go nie zakłada, tylko wypełnia podfoldery w środku.
  2. Dodaj tabelę adresową .xlsx. Skrót .gsheet z Dysku Google trzeba najpierw samodzielnie wyeksportować (Plik → Pobierz → Microsoft Excel).
  3. Sprawdź podgląd planowanej struktury podfolderów.
  4. Kliknij Utwórz foldery.
  5. Sprawdź wynik. Foldery, które już istniały, nie są nadpisywane ani czyszczone.
Zakres

Program tworzy wyłącznie podfoldery WM, pompy, kolektory i kotły. Wszystko poza tą strukturą nadal trzeba tworzyć ręcznie.

Szczegóły pól i ekranów

Folder inwestycji
Folder inwestycji musi już istnieć - ta appka go NIE zakłada, tylko wypełnia podfoldery w środku. Wszystko poza wymienioną strukturą (WM/pompy/kolektory/kotły) trzeba nadal tworzyć ręcznie. W drugim trybie ("same foldery z adresów") folder docelowy również musi istnieć i być pusty.
Tabela adresowa (.gsheet)
Podgląd wczytuje się automatycznie po wybraniu pliku. Skrót .gsheet w folderze inwestycji trzeba samodzielnie wyeksportować do .xlsx (Plik → Pobierz → Microsoft Excel).

Możliwe błędy i co zrobić

„Folder inwestycji nie istnieje: …”
Ta appka wypełnia JUŻ ISTNIEJĄCY folder inwestycji, nie tworzy go od zera — wskaż poprawną, już istniejącą ścieżkę.
„Dozwolone są tylko pliki .xlsx”
Zapisz plik jako .xlsx (Plik → Zapisz jako) — stare .xls nie są obsługiwane.
„Plik nie wygląda jak poprawny XLSX. Sprawdź, czy to nie jest skrót .gsheet…”
Skrót .gsheet z Dysku Google trzeba najpierw ręcznie wyeksportować do prawdziwego pliku Excel (Plik → Pobierz → Microsoft Excel), zanim go tu wgrasz.
„Kolumna LP jest pusta w niektórych wierszach (…)”
Program celowo nie zgaduje numeru porządkowego — uzupełnij LP dla każdego adresu w Excelu i wgraj plik ponownie.
„Nie przesłano pliku Excel”
Sprawdź, czy plik faktycznie się wybrał (pole pliku pod „Tabela adresowa”) przed kliknięciem dalej.
Przeglądarka folderów nie widzi dysku sieciowego
Wpisz ścieżkę ręcznie w polu tekstowym zamiast korzystać z przycisku Przeglądaj.
