Karty katalogowe

Wskaż Excel z arkuszami „Solary {gmina}” i folder z projektami — program sam dobierze i skopiuje karty katalogowe (grupa pompowa, kolektor, zasobnik) do folderów klientów na podstawie kolumny UID.

Jak działa?

Wybierz plik Excel.
Podaj ścieżkę do folderu Kolektory.
Uruchom najpierw podgląd, potem kopiowanie.

Ustawienia

Program sam znajdzie w środku folder „karty” (źródłowe PDF-y) oraz „Projekty\{gmina}\{id} - adres”.
